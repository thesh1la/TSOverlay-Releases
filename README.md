# TS Overlay

TS Overlay — оверлей для **TeamSpeak 3**, который показывает голосовую активность и выбранные каналы поверх игры без внедрения DLL в игровой процесс.

> В репозитории публикуются только готовые установщики и сведения об обновлениях. Исходный код приложения не распространяется.

## Скачать

Актуальная версия: **1.0.0**.

Скачайте `TSOverlay-Setup-1.0.0-win64.exe` со страницы [Releases](https://github.com/thesh1la/TSOverlay-Releases/releases/latest).

## Системные требования

- Windows 10 или Windows 11, x64;
- TeamSpeak 3 Client 3.5.6 x64;
- игра в оконном режиме или Borderless Fullscreen;
- доступ к GitHub для автоматической проверки обновлений.

Exclusive Fullscreen официально не поддерживается. Оверлей не внедряется в игру, не изменяет игровые файлы и не взаимодействует с античитом.

## Установка

1. Полностью закройте TeamSpeak, включая значок в системном трее.
2. Закройте ранее запущенный TS Overlay.
3. Запустите `TSOverlay-Setup-1.0.0-win64.exe`.
4. После установки откройте TeamSpeak.
5. Перейдите в `Инструменты → Параметры → Дополнения` и убедитесь, что плагин **TS Overlay** включён.
6. Запустите приложение TS Overlay.

Приложение устанавливается в `%LocalAppData%\Programs\TSOverlay`, а плагин — в `%AppData%\TS3Client\plugins\ts_overlay_win64.dll`. Папка, в которой установлен сам TeamSpeak, обычно значения не имеет.

Для portable-версии TeamSpeak с нестандартной папкой профиля DLL может потребоваться вручную скопировать в папку `plugins` используемого профиля.

## Первый запуск

1. Запустите TeamSpeak и подключитесь к серверу.
2. Запустите TS Overlay и дождитесь статуса подключения.
3. В разделе **Система** выберите запущенную игру или приложение, в котором должен отображаться оверлей.
4. В разделе **Мониторинг каналов** отметьте нужные каналы и при необходимости включите отображение их состава.
5. Настройте внешний вид и расположение блоков.
6. Нажмите **Сохранить**.

## Возможности

### Текущий канал

- название канала, в котором находится пользователь;
- список участников и одновременная подсветка нескольких говорящих;
- отдельное заметное оформление входящего шёпота, включая шёпот из другого канала;
- значки выключенного микрофона и звука;
- выделение собственного никнейма;
- выбор, поднимать ли говорящих выше остальных.

### Мониторинг каналов

- несколько выбранных каналов одновременно;
- количество участников и состав непосредственно под названием канала;
- разные цвета текста и фона для занятого, пустого и текущего канала;
- псевдонимы и ручной порядок каналов;
- переход в выбранные каналы по хоткеям TeamSpeak;
- постоянный заголовок **Мониторинг каналов**.

### Избранные пользователи

- избранные сохраняются между запусками;
- пользователь отображается даже в канале, который не добавлен в мониторинг;
- отдельный цвет, значок и дополнительная обводка;
- глобальный хоткей перехода в канал к первому доступному избранному;
- избранный не дублируется в мониторинге, если уже находится с вами.

### Аудит действий

- события входа, выхода и перехода между каналами;
- ограничение количества записей;
- постоянное хранение последних событий либо исчезновение по таймеру;
- отдельный блок с заголовком **Аудит действий**.

### Настройка оформления

- выбор шрифта, размера и цветов;
- фон можно отключить или изменить;
- масштаб, прозрачность, отступы и скругление;
- независимый размер блоков в режиме перемещения;
- автоматическое связывание оверлеев друг с другом;
- полный сброс оформления, размеров, цветов и расположения без удаления избранных и выбранных каналов.

## Горячие клавиши

Стандартные сочетания можно заменить на любые удобные:

- `Ctrl + Alt + F9` — включить или выключить весь оверлей;
- `Ctrl + Alt + F10` — текущий канал и участники;
- `Ctrl + Alt + F11` — мониторинг выбранных каналов;
- `Ctrl + Alt + F12` — режим перемещения;
- переход к избранному — по умолчанию не назначен.

Хоткеи перехода в конкретные выбранные каналы назначаются в настройках горячих клавиш TeamSpeak.

## Автоматические обновления

По умолчанию приложение проверяет `update.json` в этом репозитории при запуске. Проверку можно отключить или запустить вручную в разделе **Система**.

Перед установкой обновления приложение:

1. скачивает установщик только по HTTPS;
2. проверяет его SHA-256;
3. просит полностью закрыть TeamSpeak;
4. запускает обычный установщик.

Настройки пользователя при обновлении сохраняются.

## Статусы подключения

- **Ожидание запуска TeamSpeak** — клиент TeamSpeak не запущен;
- **TeamSpeak запущен — плагин не подключён** — проверьте дополнения и перезапустите TeamSpeak;
- **Плагин подключён — ожидание подключения к серверу** — TeamSpeak запущен, но сервер ещё не выбран;
- **Подключено: ...** — приложение получает данные сервера.

## Если оверлей не отображается

- убедитесь, что плагин включён в TeamSpeak;
- перезапустите TeamSpeak после установки или обновления;
- проверьте выбранный игровой процесс в разделе **Система**;
- используйте оконный режим или Borderless Fullscreen;
- нажмите **Сбросить все параметры оверлея**, если блок оказался за пределами экрана;
- откройте технический журнал из приложения, если проблема сохраняется.

TeamSpeak не позволяет плагину обходить серверные права. Если канал или его участники недоступны текущему пользователю, оверлей также не сможет получить эти сведения.

## Удаление

Удалите **TS Overlay** через `Параметры Windows → Приложения → Установленные приложения`.

Пользовательские параметры хранятся в `%AppData%\TSOverlay`. Их можно удалить вручную, если требуется полностью чистая переустановка.

## Конфиденциальность

Данные TeamSpeak передаются только между локальным плагином и локальным приложением через защищённый Named Pipe. ServerQuery и внешняя отправка списка участников не используются. Для проверки обновлений выполняется запрос только к GitHub.
