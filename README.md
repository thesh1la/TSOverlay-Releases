# TS Overlay

Оверлей TeamSpeak 3 для игр: показывает текущий канал, говорящих пользователей и выбранные каналы поверх игрового окна.

## Скачать

Актуальная версия: **1.1.0**.

**[Скачать TS Overlay](https://github.com/thesh1la/TSOverlay-Releases/releases/latest)**

## Требования

- Windows 10 или Windows 11, x64;
- TeamSpeak 3 Client 3.5.6 x64 или 3.6.0 и новее x64.

## Установка

1. Полностью закройте TeamSpeak, включая значок в трее.
2. Скачайте и запустите `TSOverlay-Setup-1.1.0-win64.exe`.
3. Установщик сам определит версию TeamSpeak и выберет совместимый плагин. Если TeamSpeak не найден, выберите версию вручную.
4. Запустите TeamSpeak.
5. Откройте `Инструменты → Параметры → Дополнения` и убедитесь, что плагин **TS Overlay** включён.
6. Запустите TS Overlay, выберите игру во вкладке **Система** и настройте нужные каналы.

Если используется portable-версия TeamSpeak, плагин может потребоваться вручную скопировать в папку `plugins` используемого профиля.

## Возможности

- текущий канал и список его участников;
- подсветка говорящих и отдельное отображение шёпота;
- мониторинг нескольких каналов и их участников;
- избранные пользователи;
- события входа, выхода и перехода между каналами;
- переход в каналы по горячим клавишам;
- выбор цветов, шрифта, фона, масштаба и расположения блоков;
- привязка блоков друг к другу;
- импорт и экспорт настроек;
- автоматические обновления.

## Горячие клавиши по умолчанию

- `Ctrl + Alt + F9` — весь оверлей;
- `Ctrl + Alt + F10` — текущий канал;
- `Ctrl + Alt + F11` — мониторинг каналов;
- `Ctrl + Alt + F12` — режим перемещения.

Все сочетания, включая переходы в мониторинговые каналы, назначаются прямо в приложении.

## Если оверлей не появился

- перезапустите TeamSpeak после установки;
- проверьте, что плагин **TS Overlay** включён;
- выберите запущенную игру во вкладке **Система**;
- если конкретная игра не показывает оверлей в полноэкранном режиме, попробуйте Borderless Fullscreen;
- при необходимости сбросьте параметры оверлея.

Настройки сохраняются при обновлении и удаляются отдельно через `%AppData%\TSOverlay`.
